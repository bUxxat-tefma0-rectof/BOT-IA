# 🤖 Tech Offers Bot - Sistema Inteligente de Ofertas Tecnológicas

Sistema completo de ofertas tecnológicas integrado ao Telegram com bot único, canal de publicações, painel administrativo e sistema de alertas.

## 📋 Funcionalidades

### Para Usuários
- ✅ Verificação automática de inscrição no canal
- 🔥 Visualização de ofertas ativas
- 📂 Navegação por categorias
- 🔔 Sistema de alertas de preço
- 🛒 Links diretos para compra
- 📊 Rastreamento de origem

### Para Administrador
- 📦 CRUD completo de produtos
- 📢 Publicações automáticas no canal
- 📅 Agendamento de publicações
- 📝 Templates personalizados
- 🔘 Configuração de botões
- 📊 Estatísticas detalhadas
- 🤖 Integração com IA
- 📈 Monitoramento de preços

- PostgreSQL 15+
